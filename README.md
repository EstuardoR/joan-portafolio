# Portafolio de Joan

Portafolio personal construido con Next.js (App Router), React, TypeScript y Material UI.

## Desarrollo

```bash
yarn dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Estado actual

Scaffold mínimo: Next.js + Material UI configurado (`ThemeProvider`, `CssBaseline`, cache de Emotion para App Router en `src/app/layout.tsx`). `src/theme.ts` es el punto de partida para personalizar paleta/tipografía. Sin componentes ni secciones propias todavía — eso se construye paso a paso.
